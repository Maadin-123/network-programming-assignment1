# network-programming-assignment1
CPP 3204 Network Programming Assignment 1

 Overview
This repository contains group solutions for CPP 3204 Network Programming Assignment 1 (Group 3).  
The assignment is based on Units 1–3 of the course notes and involves practical coding tasks in Java, C++ and Python.  
Each group member contributes code, screenshots, and documentation for their assigned questions.

Repository Structure
- Unit1/ → Client-Server Model
  - Q1: Basic Helpdesk Client-Server
  - Q2: Secure Helpdesk (Threads, Validation, Logging)
  - Q3: TCP vs UDP Comparison
- Unit2/ → IP Addressing and Network Interfaces
  - Q1: Hostname and IP Resolver
  - Q2: Local Host Information
  - Q3: IPv4 and IPv6 Classification
- Unit3/ → Advanced Networking Tools
  - Q1: Network Reachability Checker
  - Q2: Port Availability Scanner
  - Q3: Tool-Based Report Command Runner

Each question folder contains:
- Source code (`.java`, `.cpp`, `.py`)
- Screenshots of program output (`/screenshots/`)
- Notes on how to run the program

  Contribution Guide
1. Work in your own branch (e.g., `ivy-unit1q1`, `john-unit2q2`).
2. Place code in the correct Unit/Q folder.
3. Save screenshots in the `screenshots/` subfolder.
4. Write clear commit messages (e.g., `Add Python code for Unit1 Q1`).
5. Submit a Pull Request for review before merging into `main`.
